# cameradenet

1つのQRコードとシンプルな整数ベースの暗号化を使用して、メッセージのリストを安全にやり取りするためのWebアプリケーションです。「cameradenet（カメラでネット）」という名前は「カメラを通じたインターネット」を意味し、データを視覚的に転送するというコア機能を反映しています。

メッセージのリスト全体が1つのQRコードにエンコードされます。別のユーザーがこのQRコードをスキャンすることで、完全なリストを自身のブラウザにインポートできます。

## 機能

- **メッセージ管理**: 一時的なリストにメッセージを追加、表示、削除できます。
- **暗号化**: メッセージ本文は共有の数値キーを使用して暗号化されます。キーが指定されていない場合は、デフォルトで `0` になります。
- **QRコード生成**: メッセージリスト全体が自動的にCSVとしてエンコードされ、スキャン可能な1つのQRコードとして描画されます。
- **QRコードスキャン**: デバイスのカメラを使用してQRコードをスキャンし、メッセージリストをインポートできます。
- **ブラウザ内での復号**: リスト内の暗号化されたメッセージ本文をクリックすると、復号されて内容が表示されます。
- **スタンドアロン**: バックエンドやインストールは不要で、すべてブラウザ上で動作します。

## 使い方

1. **名前**、**宛先**、**本文**を入力します。
2. （オプション）暗号化に使用する数値の**共通鍵**を入力します。
3. **登録**ボタンをクリックします。メッセージが暗号化されて右側のリストに追加され、QRコードが更新されます。
4. メッセージをインポートするには、カメラビューを使用して、別のアプリインスタンスで生成されたQRコードをスキャンします。
5. メッセージを復号するには、リスト内の本文テキストをクリックします。復号された内容がアラートで表示されます。
6. メッセージを削除するには、その行の **🗑️** アイコンをクリックします。

*注意: メッセージはブラウザのメモリにのみ保存されるため、ページを閉じたり再読み込みしたりすると失われます。メッセージリストが大きくなりすぎると、データ容量を超えるためQRコードは表示されなくなります。*

## 依存関係

このプロジェクトでは、以下のライブラリを動的に読み込んで使用しています。

- [QR-Code-Reader](https://github.com/code4fukui/qr-code-reader): QRコードのスキャン用。
- [Ango.js](https://github.com/code4fukui/Ango): 暗号化および復号用。
- [QRCode.js](https://js.sabae.cc/QRCode.js): QRコードの生成用。
- [CSV.js](https://js.sabae.cc/CSV.js): データのシリアライズ用。
