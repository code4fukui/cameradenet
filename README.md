# cameradenet

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A web application to exchange lists of messages securely using a single QR code and simple integer-based encryption. The name "cameradenet" translates to "Internet via Camera," reflecting its core function of transferring data visually.

The entire list of messages is encoded into a single QR code. Another user can scan this QR code to import the complete list into their own browser.

## Features

-   **Message Management**: Add, view, and delete messages in a temporary list.
-   **Encryption**: Message bodies are encrypted using a shared numeric key. If no key is provided, it defaults to `0`.
-   **QR Code Generation**: The entire message list is automatically encoded as CSV and rendered as a single, scannable QR code.
-   **QR Code Scanning**: Use your device's camera to scan a QR code and import a message list.
-   **In-Browser Decryption**: Click on an encrypted message body in the list to decrypt and view its content.
-   **Standalone**: Runs entirely in the browser with no backend or installation required.

## How to Use

1.  Enter your **Name**, a **Recipient**, and the **Message** text.
2.  (Optional) Enter a numeric **Shared Key** to use for encryption.
3.  Click the **Register** (登録) button. The message is encrypted and added to the list on the right, and the QR code updates.
4.  To import messages, use the camera view to scan a QR code generated by another instance of the app.
5.  To decrypt a message, click its body text in the list. An alert will show the decrypted content.
6.  To delete a message, click the **🗑️** icon in its row.

*Note: Messages are stored only in your browser's memory and will be lost when the page is closed or refreshed. If the message list becomes too large, the QR code will disappear as it has exceeded its data capacity.*

## Dependencies

This project uses the following libraries, which are loaded dynamically:

-   [QR-Code-Reader](https://github.com/code4fukui/qr-code-reader) for scanning QR codes.
-   [Ango.js](https://github.com/code4fukui/Ango) for encryption and decryption.
-   [QRCode.js](https://js.sabae.cc/QRCode.js) for generating QR codes.
-   [CSV.js](https://js.sabae.cc/CSV.js) for data serialization.
